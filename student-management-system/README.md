## 1. Project Description

The Interactive Student Management System is a responsive web application developed to manage student records efficiently. The application allows users to add, view, edit, search, filter and delete student records through a user-friendly interface.

It includes form validation, confirmation modals, dashboard statistics and browser-based data persistence. The system is designed to make student information easier to manage while providing a clean and professional user experience.

## 2. Project Objectives

The main objectives of this project are to:

- Develop an interactive web application for managing student records.
- Allow users to add, view, update and delete student information.
- Provide search and filtering functionality.
- Validate information entered into forms.
- Display useful student statistics on a dashboard.
- Create a responsive interface for different screen sizes.
- Deploy the application online using Vercel.

## 3. Technologies Used

The following technologies and tools were used to develop and deploy the application:

- **React:** Used to build reusable user interface components.
- **JavaScript:** Used to implement application functionality and interactivity.
- **Vite:** Used as the development server and build tool.
- **CSS:** Used to style the application and create a responsive layout.
- **GitHub:** Used to store and manage the project's source code.
- **Vercel:** Used to deploy and host the live application.

## 4. System Features

The application provides the following features:

- **Add Student Records:** Allows users to enter and save student information.
- **View Student Records:** Displays student information in an organised format.
- **Edit Student Records:** Allows existing student information to be updated.
- **Delete Student Records:** Allows users to remove student records.
- **Search Students:** Enables users to find specific student records.
- **Filter Students:** Allows records to be filtered according to available criteria.
- **Dashboard Statistics:** Displays summaries of student information.
- **Form Validation:** Helps prevent incomplete or invalid information from being submitted.
- **Confirmation Modals:** Requests confirmation before certain actions, such as deleting a record.
- **Responsive Design:** Provides a layout that adapts to different screen sizes.
- **Browser-Based Data Persistence:** Stores data in the browser so that it can remain available after refreshing the page, subject to the browser storage used by the application.

## 5. Installation and Running Instructions

To run the project locally on a computer, follow these steps:

1. Install Node.js and npm.
2. Clone the GitHub repository:

   `git clone https://github.com/fusimotheo648-cell/management_system.git`

3. Open the project folder in a terminal.
4. Install the required dependencies:

   `npm install`

5. Start the development server:

   `npm run dev`

6. Open the local URL displayed in the terminal in a web browser.

**Note:** Run the commands from the directory containing the project's `package.json` file.
